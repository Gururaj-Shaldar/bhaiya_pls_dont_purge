# Transformation

## Approach and Solution
Downloaded the file given. Opened it and found a set of chinese characters. Try to put in on google translate but no sucess. Then, I tried to understand what that given function meant in the CTF description. 
Asked AI, to explain what it means. It said that this is a python code to convert 8-bit ASCII characters into UTF-16(Unicode Text Format-16)(16 bits). Then I asked how it works but didnt understand. 
It gave a python code to reverse it back into the code, ran that and obtained the flag.
